## 🛠️ Tech Stack
- ESP32 + Panneau Solaire 50W
- Contrôle 4G via téléphone
- Batterie Lithium 12V
- Code Open Source

## 🌍 Impact
Sécurité routière à Kingabwa, Limete, Kinshasa - Réduit les accidents
